# Missions

Create one folder per cross-project mission. Suggested contents:

- `BRIEF.md` — original request and constraints.
- `CONTRACT.md` — observable outcome, invariants, verification, rollback, and in-hand check.
- `STATE.md` — lanes, owners, baselines, write sets, and current status.
- `DECISIONS.md` — unresolved forks requiring the user's ruling.
- `REPORT.md` — evidence-backed handoff.

Single-repository implementation notes belong in that repository unless the mission genuinely
spans projects.
